# المساعد القانوني الذكي — AI Legal Research Assistant

منصة بحث قانوني مغلقة المصدر (Closed-Domain RAG) للمحامين. تجيب حصراً من القوانين والقرارات القضائية المخزّنة، وإذا لم تجد سنداً تصرّح بذلك بدل أن تخترع.

---

## المبدأ الحاكم

النموذج **ممنوع** من استخدام معرفته العامة. تُفرض هذه القاعدة على ثلاث طبقات، لأن الاعتماد على طبقة واحدة (الـ prompt) غير كافٍ:

| الطبقة | الملف | الوظيفة |
|---|---|---|
| بوابة الصلة | `src/lib/search/hybrid.ts` | تُسقط المقاطع تحت `RETRIEVAL_MIN_SCORE`. بلا هذه البوابة يُعيد pgvector دائماً "أقل النتائج بُعداً" مهما كان السؤال. |
| التوقّف المبكر | `src/app/api/chat/route.ts` | إذا لم يعبر أي مقطع البوابة، يُعاد نص الرفض بلا استدعاء النموذج إطلاقاً — صفر tokens وصفر فرصة للهلوسة. |
| قواعد الـ prompt | `src/lib/ai/prompts.ts` | تمنع الاستشهاد بغير المرفق وتفرض `[1]` على كل معلومة. |

نص الرفض ثابت في `NO_BASIS_ANSWER`، وتعتمد عليه واجهة المستخدم وعمود `chat_history.grounded`.

### الإجابة العامة عند غياب السند — ولماذا الحارس بالكود

`ALLOW_GENERAL_FALLBACK=true` (الافتراضي): إن لم تجد القاعدة سنداً، يجيب النظام من معرفته العامة **توجيهاً مفاهيمياً فقط**.

**البرومت وحده لا يكفي، وهذه ليست مسألة صياغة.** حين تُطلب من نموذج إجابة عن القانون الأردني من ذاكرته، فهو **يولّد نصاً محتملاً لا يسترجع حقيقة** — فيكتب «المادة 780 من القانون المدني تنص على...» بثقة تامة، والرقم خاطئ. أقوى برومت لا يمنع هذا؛ الخلل في طبيعة النموذج لا في التعليمات.

لذلك: **البرومت يوجّه، و`src/lib/ai/guard.ts` ينفّذ.** يمسح كل إجابة غير مُسنَدة ويحجب أي رقم مادة أو قرار أو قانون قبل إرسالها — بغض النظر عمّا قرر النموذج كتابته.

| | يمر | يُحجب |
|---|---|---|
| مثال | «عقد المقاولة يخضع لأحكام القانون المدني» | «المادة 780 من القانون المدني تنص على...» |
| السبب | توجيه عام مفيد وغير خطر | **استشهاد مُختلَق** يوقّع عليه المحامي باسمه |

قياس فعلي على مخرَج نموذجي: خمس إشارات مُختلَقة (`المادة 780`، `المادة (5)`، `رقم 1234/2020`، `قانون العمل رقم 8 لسنة 1996`، `لسنة 1996`) حُجبت كلها، والمفهوم العام نجا سليماً.

**قرارات مقصودة:**
- **الإجابة العامة لا تُبثّ حرفاً بحرف** — لا يمكن حجب رمز أُرسل. البث كان سيعرض «المادة 780» ثم يسحبها، والقارئ قرأها.
- **تُحجب ولا تُحذف** — الفراغ المعلَّم يخبر المحامي أن النظام حجب شيئاً وسببه؛ الحذف الصامت يترك نصاً يبدو كاملاً وموثوقاً وقد اختفت منه التفصيلة الحاملة.
- **تُسيَّج بصرياً** بصندوق كهرماني «إجابة عامة» **قبل** النص لا تحته — التنويه أسفل إجابة تُقرأ بعد أن وُثق بها.
- **تُسجَّل `grounded=false`** — نسبة الإجابات المُسنَدة في اللوحة تظل تعدّها غير مُسنَدة.
- **يُسجَّل كل حجب في السجل** — معدّل مخالفة النموذج للبرومت يُقاس ولا يُفترض.

للعودة إلى الرفض فقط: `ALLOW_GENERAL_FALLBACK=false`.

### سجل المحادثات

في `localStorage` لا على الخادم — لا يوجد تسجيل دخول في هذه المرحلة، فلا هوية يُربط بها السجل. الخيار مقصود لا اختصار: المتصفح هو الوحيد الذي يعرف «محادثاتي». الثمن أن مسح بيانات المتصفح يمحوها، وأنها لا تنتقل بين الأجهزة — مقبول قبل تسجيل الدخول، ويُنقل إلى الخادم معه.

`src/lib/history.ts` يحفظ آخر 50 محادثة، ويُسقط الأدوار المعلّقة والفاشلة قبل الحفظ — إجابة نصفها مبثوث تُستعاد من السجل تبدو إجابة حقيقية توقّفت في منتصف الجملة.

**الوضع (`mode`) يُحفظ مع كل رسالة**، فتُستعاد الإجابة العامة داخل سياجها الكهرماني كما كانت حيّة. بدونه كانت تُعرض عند إعادة الفتح كإجابة عادية — أي **أكثر موثوقية بعد الاستعادة مما كانت وقت توليدها**. مُتحقَّق منه فعلياً في المتصفح: التسمية والتنويه وإشعار الحجب تصمد كلها بعد إعادة التحميل والفتح من السجل.

`chat_history.mode` في قاعدة البيانات يخدم لوحة الإدارة لا الواجهة: `grounded=false` وحده صار غامضاً بعد إضافة الإجابة العامة — يعني «رُفض» أو «أُجيب من المعرفة العامة»، وهما مختلفان تماماً. الأول يسمّي قانوناً يستحق الرفع، والثاني لا يستدعي شيئاً. لذلك تعرض اللوحة ثلاث حالات: **مُسنَد / عام / مرفوض**.

## المتطلبات

- Node.js 20+

## المحادثة والـ embeddings مزوّدان منفصلان

**Anthropic لا تقدّم embeddings إطلاقاً.** Claude للمحادثة فقط — لا نموذج embedding ولا endpoint. وبما أن نصف النظام مبني على الـ embeddings، فإن "استخدم Claude" يعني حتماً: **Claude للإجابات + مزوّد ثانٍ للمتجهات**. لا مفر.

لذلك العقد مفصول إلى `ChatProvider` و`EmbeddingProvider` في `src/lib/ai/provider.ts`. الواجهة الموحّدة الأولى (`AIProvider` بـ `chat()` و`embed()` معاً) افترضت أن مزوّداً واحداً يفعل الاثنين — وهو افتراض يجعل استخدام Claude **غير قابل للتعبير عنه**.

| الوظيفة | الخيارات | المتغيّر |
|---|---|---|
| المحادثة | `openai` \| `anthropic` | `CHAT_PROVIDER` |
| Embeddings | `openai` \| `voyage` — **لا `anthropic`** | `EMBEDDING_PROVIDER` |

للتحويل إلى Claude:

```bash
CHAT_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-opus-4-8
# EMBEDDING_PROVIDER يبقى openai أو voyage — لا خيار ثالث
```

**تنبيه التكلفة:** `claude-opus-4-8` أغلى من `gpt-4o-mini` بـ **~33× على المدخلات و~42× على المخرجات**. على تطبيق عام بلا تسجيل دخول، هذا الفرق **هو نموذج التكلفة كله** لا تفصيل فيه. الافتراضي `gpt-4o-mini` لهذا السبب — غيّره بوعي.

**تغيير مزوّد أو نموذج الـ embeddings ليس تبديل إعداد:** عرض عمود `embedding` مثبّت وقت الترحيل. `text-embedding-3-small` بـ1536 و`voyage-3-large` بـ1024. التغيير يعني ترحيلاً على قاعدة فارغة **وإعادة فهرسة المجموعة كاملة**.

## التشغيل محلياً

```bash
cp .env.example .env      # املأ OPENAI_API_KEY و ADMIN_PASSWORD و IP_HASH_SALT
docker compose up -d db   # Postgres + pgvector جاهزة
npm install
npm run db:migrate        # ينشئ الجداول والفهارس
npm run db:seed           # اختياري: عيّنات لاختبار البحث بلا رفع PDF
npm run dev
```

- الواجهة: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin`

**بدون Docker؟** أي Postgres فيه pgvector يكفي — بما فيها Neon أو Supabase (كلاهما يوفّر pgvector على الخطة المجانية). ضع رابط الاتصال في `DATABASE_URL` وشغّل `npm run db:migrate`.

**قاعدة بعيدة (Neon وغيرها):** أوامر الترحيل والفهرسة وإصلاح المجموعة (`db:migrate` و`ingest` و`corpus:integrity` و`reindex` و`backfill-*` و`link-amendments`) تطبع هدفها (المضيف، القاعدة، البيئة)، وحين تكتب ترفض قاعدة بعيدة لم تُعلَن بيئتها؛ أما التشغيل التجريبي (`--dry-run`، أو دون `--apply`) فيقرأ فقط ولا يُرفض. `deploy/ingest-all.sh` يطبّق الترحيل أولاً حتى مع `--dry-run`، فيحتاج على الإنتاج `CONFIRM_PRODUCTION=yes`. بيانات `db:seed` وبيانات التقييم الاصطناعية لا تُحمَّل إلا في قاعدة محلية أو staging. اضبط `DATABASE_ENVIRONMENT=branch` (أو `staging`)، وضع مضيف الإنتاج في `PRODUCTION_DATABASE_HOST` حتى يُرفض ولو أُعلن خطأً أنه فرع؛ الإنتاج نفسه يحتاج `--confirm-production`. `npm run db:identity` يطبع هوية القاعدة وإصدار مخططها دون أي بيانات اعتماد. إن كان المنفذ 5432 محجوباً في شبكتك: `DATABASE_TRANSPORT=neon-websocket`. خطوات التحقق الحي كاملة: `deploy/live-corpus-sequence.sh`.

## بناء قاعدة المعرفة بالجملة

لوحة الإدارة ترفع ملفاً واحداً في المرة — لا تصلح لمئات القرارات. لذلك:

```bash
# 1) خطّط وسعّر أولاً. لا يكتب شيئاً ولا يستدعي أي API، ويعمل حتى بلا قاعدة بيانات.
npm run ingest -- "D:/legal/tamyeez" --dry-run

# 2) نفّذ
npm run ingest -- "D:/legal/tamyeez" --court="محكمة التمييز" --category=حقوقية

# 3) دفعة صغيرة أولاً للتحقق من التكلفة الحقيقية قبل الالتزام بالكل
npm run ingest -- "D:/legal" --limit=10
```

| الخيار | الأثر |
|---|---|
| `--type=` | `law` \| `regulation` \| `instruction` \| `court_decision` \| `principle` \| `template`. الافتراضي: يُستنتج من اسم المجلد (`tamyeez`، `قوانين`، `نماذج`...). |
| `--category=` `--court=` `--year=` | تُطبَّق على كل ملفات الدفعة. |
| `--dry-run` | خطة وتقدير تكلفة. بلا كتابة وبلا استدعاءات. |
| `--limit=n` | توقّف بعد n ملفاً. |
| `--force` | أعد فهرسة ما هو مفهرس أصلاً. |

**الأمان في التشغيل:** كل ملف يُثبَّت وحده، فالمقاطعة بـ Ctrl+C تكلفك الملف الجاري فقط. إعادة التشغيل تتخطى ما نجح — البصمة (SHA-256) هي ما يمنع الدفع مرتين. ملف تالف واحد لا يُنهي دفعة من 300: يُسجَّل بحالة "فشل" ويظهر في `/admin` لإعادة المحاولة.

**كشف التكرار يعمل على المحتوى لا الاسم:** نفس القرار محفوظاً باسمين مختلفين يُفهرس مرة واحدة. وعند التساوي يُختار الاسم الأنظف — `qarar_1234_2020.pdf` يفوز على `DUPLICATE_copy.pdf`، لأن العنوان يظهر في كل بطاقة استشهاد يقرأها المحامي.

### الطريق السريع: كل شيء بأمر واحد

```bash
bash deploy/ingest-all.sh --dry-run    # الخطة والتكلفة — لا يكتب شيئاً ولا يستدعي أي API
bash deploy/ingest-all.sh              # التنفيذ
```

ينزّل ويفهرس المجموعة كاملة بالترتيب والخيارات الصحيحة لكل دفعة (وهي **ليست** قابلة للتبادل — انظر التعليقات داخل السكربت). قابل لإعادة التشغيل: البصمة تمنع الفهرسة والدفع مرتين.

يتطلب `DATABASE_URL` (Postgres + pgvector) و`OPENAI_API_KEY` في `.env` — ويتوقف فوراً وبرسالة واضحة إن نقص أيهما.

### تنزيل المصادر يدوياً

القوائم جاهزة ومحفوظة في `deploy/sources/`. **69 ملفاً، 1705 صفحة، ~30MB:**

```bash
# القوانين (24) — المدني 1976، العقوبات 1960، أصول المحاكمات الجزائية 1961 والمدنية 1988، التنفيذ...
npm run fetch  -- --list=deploy/sources/moj-laws-ar.txt --out=./downloads/moj-laws
npm run ingest -- ./downloads/moj-laws --type=law

# الأنظمة والتعليمات (35) — بلا --type عمداً، انظر أدناه
npm run fetch  -- --list=deploy/sources/moj-regulations-ar.txt --out=./downloads/moj-regs
npm run ingest -- ./downloads/moj-regs

# الدستور (10 فصول) — الخياران إلزاميان، انظر أدناه
npm run fetch  -- --list=deploy/sources/moj-constitution-ar.txt --out=./downloads/moj-dustour
npm run ingest -- ./downloads/moj-dustour --type=law --title-prefix="الدستور الأردني"

# قرارات الديوان الخاص بتفسير القانون (78 نصاً + بعض المرفقات) — أنظف مصدر متاح
npm run fetch  -- --list=deploy/sources/jc-diwan-decisions.txt --out=./downloads/jc-diwan --as-text="#MainContent_DivContent"
npm run fetch  -- --list=deploy/sources/jc-diwan-decisions.txt --out=./downloads/jc-diwan --match=news_new
npm run ingest -- ./downloads/jc-diwan --type=principle --title-prefix="قرار الديوان الخاص بتفسير القانون"

# أحدث قرارات المحاكم من نقابة المحامين (8، مختلطة)

npm run ingest -- ./downloads/jba-decisions --type=court_decision
```

### قرارات محكمة التمييز — اقرأ هذا قبل أن تسأل عنها

**لا يوجد مصدر مجاني يوفّر قرارات محكمة التمييز الأردنية بالجملة.** هذه حقيقة بنيوية في النشر القانوني الأردني، لا عائق تقني:

| المصدر | الوضع |
|---|---|
| قسطاس / مركز عدالة | أرشيف شامل (1901-2026) — **باشتراك مدفوع** |
| المجلس القضائي (jc.jo) | **لا ينشر قرارات التمييز إطلاقاً** — فُحصت كل أقسامه |
| وزارة العدل | تشريعات فقط، لا قرارات |
| نقابة المحامين | 8 قرارات "مستجدة" فقط، مختلطة المحاكم، وتتغيّر |

الطرق المشروعة أمامك:

1. **قرارات الديوان الخاص بتفسير القانون (78 قراراً — مُنزَّلة بالفعل).** ليست قرارات تمييز، لكنها تفسيرات **مُلزِمة لجميع المحاكم**، ويصدرها ديوان يرأسه رئيس محكمة التمييز. أقرب ما يتوفر مجاناً ورسمياً إلى الاجتهاد المُلزِم.
2. **اشتراكك في قسطاس أو عدالة** — إن كان لديك اشتراك، استخدم التصدير المسموح ضمن شروطه. السحب الآلي يخالف الشروط ويعرّض اشتراكك للإلغاء، ولن تجد هنا أداة تفعله.
3. **أرشيفك المهني** — القرارات التي تسلّمتها بصفتك وكيلاً. هذا أفضل مصدر عملي لمحامٍ ممارس: `npm run ingest -- <مجلدك> --type=court_decision`. **لكن راجع كل ملف قبل رفعه:** قاعدة المعرفة عامة ويقتبس منها أي زائر مجهول (انظر "ما يجوز وضعه هنا" أدناه).

**لا يوجد قسم "تعليمات" منفصل على الموقع** — التعليمات مبثوثة داخل قسم "الأنظمة". لذلك لا تمرّر `--type` لتلك الدفعة: يستنتج `src/lib/ingest/classify.ts` النوع من الكلمة الأولى في اسم كل ملف (نظام → `regulation`، تعليمات → `instruction`، لائحة → `template`). النتيجة الفعلية على الـ35: 24 نظاماً، 8 تعليمات، لائحة، وقرار وزاري.

**الدستور يحتاج الخيارين:** ملفاته اسمها `الفصل01`..`الفصل10` — لا تدل على نوعها ولا تصلح عنواناً. بلا `--title-prefix` تظهر بطاقة الاستشهاد بعنوان "الفصل07" وحده.

#### قواعد التصنيف — ولماذا هي بهذا الترتيب

| القاعدة | السبب |
|---|---|
| الكلمة الأولى في اسم الملف أولاً | الوثائق الأردنية تُسمّى بنوعها أولاً: "نظام رسوم..."، "تعليمات المراقبة..." |
| ثم تطابق جزئي، **الأندر أولاً** | "نظام معدل لنظام المساعدة **القانونية**" يحتوي "قانون". فحص القانون قبل النظام يصنّف النظام قانوناً. |
| اسم المجلد **أخيراً** | مجلد اسمه `moj-laws` يحتوي "law" فيَسِم كل ملف فيه بـ"قانون" — بما فيها الأنظمة. |
| المجهول ⇒ توقّف، لا تخمّن | الافتراضي القديم كان "قرار محكمة"، فكان يفهرس **الدستور** كقرار محكمة. النوع يقود فلتر البحث واستراتيجية التقطيع: المصدر المُصنَّف خطأً يُفهرس لكنه يصير غير مرئي للأسئلة التي يفترض أن يجيبها — بلا أي خطأ يُنبّهك. |

> تحذير للصيانة: لا تستخدم `\b` في أنماط عربية. `\b` في جافاسكربت معرّفة على `[A-Za-z0-9_]`، فلا حدّ كلمة بعد حرف عربي و`/^نظام\b/` لا تطابق شيئاً أبداً. كُتبت هذه الأنماط بـ`\b` أولاً فكانت **ميتة بالكامل**، ونجحت الاختبارات صدفةً لأن التطابق الجزئي أعطى النتيجة الصحيحة في الحالات المغطاة. الحارس الصحيح: `(?![؀-ۿ])`.

**لماذا قائمة يدوية بدل زحف آلي:** ترقيم صفحات الموقع يتم عبر `__doPostBack` مع `__VIEWSTATE` — لا روابط صفحات يمكن قراءتها. وأمام الموقع جدار حماية F5 (يرفض `Mozilla/5.0` المزيّف). إرسال POST متكرر بـ viewstate هو النمط الذي نُصب الجدار لصيده. جُمعت الروابط مرة واحدة بمتصفح حقيقي، والتنزيل بعدها ملفات ثابتة عادية. للتحديث: افتح الصفحات الثلاث وأضف الجديد إلى الملف.

ولأي مصدر HTML عادي آخر:

```bash
npm run fetch -- "<listing-url>" --out=./downloads/x --dry-run

`fetch` يقرأ HTML عادياً فقط: يحترم `robots.txt`، ويطلب طلباً واحداً كل 1.5 ثانية بالتسلسل، ويعرّف نفسه في الـ User-Agent. **لا** يشغّل JavaScript ولا يلتف على WAF.

**`lob.gov.jo` (ديوان التشريع) لا يعمل مع هذه الأداة، وهذا مقصود.** حمولات الـ API لديه مشفّرة بـ AES من طرف المتصفح (`{"enc":"U2FsdGVkX1..."}`) وخلفه جدار حماية. كتابة سكربت له يعني فكّ تشفيره والالتفاف على الجدار: هشّ (يتعطل مع أي تحديث)، ويعرّض IP الخادم الوحيد للحظر فيسقط الموقع كله، وهو التفاف على حماية تقنية لموقع حكومي. استخدمه يدوياً ووجّه `npm run ingest` إلى مجلد تنزيلاتك.

### تحذير جوهري: جودة النص العربي في ملفات الجريدة الرسمية

ملفات الجريدة الرسمية الأردنية تُدمج خطوطاً بجدول `ToUnicode` تالف. الصفحة تظهر سليمة في أي قارئ، لكن طبقة النص تُخرج خردة:

```
اٌّبصح 3 - ٠ـّٝ ٘ظا اٌمابْٔٛ      ←  الغرض: "المادة 1 - يسمى هذا القانون"
```

`src/lib/ingest/quality.ts` يكشف هذا ويجبر النظام على OCR. الكشف بـ**تنوّع المفردات** لا بكثافتها: يَعُدّ كم كلمة عربية شائعة *مختلفة* ظهرت. القياس الفعلي على الـ24 قانوناً: التالف **1-3** كلمات مختلفة، السليم **7-42**.

(الكثافة كانت خياري الأول وكانت خطأً: رفضت قانوناً نصه سليم لأنه صفحتان بديباجة رسمية — فالكثافة تقيس أسلوب الوثيقة لا ترميزها. التنوّع مستقل عن الطول.)

**النتيجة على الـ69 ملفاً المنزّلة (1705 صفحة):**

| الدفعة | ملفات | صفحات | نص سليم | يحتاج OCR |
|---|---|---|---|---|
| القوانين | 24 | 1360 | 20 | 4 (31ص) |
| الأنظمة والتعليمات | 35 | 280 | 29 | 6 (26ص) |
| الدستور | 10 | 65 | 9 | 1 (1ص) |
| **الإجمالي** | **69** | **1705** | **58 (1647ص)** | **11 (58ص، ~6 دقائق)** |

أي أن **97% من الصفحات نصّها سليم وأرقام موادها موثوقة** — وفيها كل القوانين الأساسية. الـ11 ملفاً المتبقية قصيرة (تعديلات حديثة) وستُحجب أرقام موادها.

### مصادر HTML: أنظف من الـ PDF

قرارات الديوان (78 ملفاً) تُنشر كصفحات ويب لا كملفات. نصها **لا يمر عبر خريطة خطوط إطلاقاً**، فلا يمكن أن يكون مشوّهاً أصلاً — ولا يحتاج OCR ولا تُحجب أرقامه. القياس: صفر تشويه، متوسط 25.9 كلمة مختلفة، `قرار رقم (1) ... بتاريخ 19/3/2019` بأرقام صحيحة.

لذلك يقبل `extractDocument` امتداد `.txt` كمُدخل من الدرجة الأولى، و`--as-text="<css-selector>"` في `fetch` يحوّل الصفحات إلى نصوص جاهزة للفهرسة.

**المُحدِّد إلزامي ولا يُخمَّن:** موقع ASP.NET يحمل في كل صفحة ~14KB من التنقّل وأدوات الوصول والتذييل. خوارزمية تخمين المحتوى قد تخلط أثاث الموقع بنص قرار قضائي يُقتبس لمحامٍ. المُشغّل ينظر إلى الصفحة مرة ويسمّي الحاوية.

**والقيد الذي يترتب على ذلك:** الـ OCR يقرأ النثر العربي جيداً (ثقة ~86%) لكنه **يخطئ في الأرقام العربية-الهندية** — `المادة ٣` تُقرأ `المادة ov` أو `المادة *-`. جُرّب مع `ara` و`ara+eng`؛ كلاهما غير موثوق.

لذلك: **أرقام المواد المستخرجة من OCR لا تُخزَّن كبيانات استشهاد** (`article_number = NULL`)، ويُوسم المصدر بملاحظة صفراء في لوحة الإدارة. النص يبقى مفهرساً وقابلاً للبحث الدلالي بالكامل — الأرقام وحدها تُحجب. رقم مادة مخمَّن هو استشهاد مُختلَق، وهو الشيء الوحيد الذي بُني هذا النظام لمنعه.

**للاستشهاد الدقيق بالمواد:** ارفع نسخة رقمية سليمة (لا ممسوحة) من القانون، أو صحّح الرقم يدوياً بعد المراجعة.

### ما يجوز وضعه هنا

`legal_sources` هي **قاعدة معرفة عامة**: أي مقطع فيها قابل للاقتباس لأي زائر مجهول (لا يوجد تسجيل دخول في هذه المرحلة). فهي مناسبة للقوانين والأنظمة والقرارات المنشورة والمبادئ والنماذج المجرّدة من بيانات الأطراف.

**ملفات الموكّلين لا توضع هنا.** لتحليل ملف قضية بعينه استخدم تبويب "تحليل قضية" في الواجهة: يُخزَّن في `uploaded_cases` مربوطاً بجلسة صاحبه، ولا يدخل قاعدة المعرفة المشتركة ولا يُقتبس لأحد آخر.

## المعمارية

```
رفع PDF (admin)
   ↓ extract.ts    نص مباشر، وOCR فقط إن بدا الملف ممسوحاً
   ↓ clean.ts      NFKC، حذف التشكيل، توحيد الأرقام، رأب الأسطر المقطوعة
   ↓ chunk.ts      قطع على حدود "المادة"، لا على عدد الحروف
   ↓ embed         دفعات 96، ترتيب مضمون بالـ index
   ↓ Postgres      chunk_text + folded_text + embedding + بيانات الاستشهاد

سؤال المستخدم
   ↓ intent.ts     هل هذا بحث عن مفهوم أم استدعاء لمادة بعينها؟
   ↓ hybrid.ts     شعاعي + كلمات مفتاحية، دمج RRF، بوابة صلة
   ↓ prompts.ts    سياق أدنى + قواعد المجال المغلق
   ↓ SSE           بث الإجابة مع بطاقات المصادر
```

### لماذا نُخزّن النص مرتين

`chunk_text` حرفي — هو ما نقتبسه للمحامي. `folded_text` مطوي (أ/إ/ا، ى/ي، ة/ه) — للبحث فقط. الطيّ لا يمكن أن يحدث وقت الاستعلام لأن الفهرس مبني على الشكل المخزّن، ولا يجوز أن يحدث في `chunk_text` لأنه يُفسد نص المادة المقتبس.

### لماذا RRF وليس جمع النقاط

تشابه الجيب التمام و `ts_rank` على مقياسين غير قابلين للمقارنة؛ معايرتهما تخمين. الرُتب قابلة للمقارنة مباشرة. الاستثناء الوحيد: مطابقة رقم مادة أو قرار تُعطى دفعة قاطعة (`+1`) لأنها ليست إشارة ترجيح — هي الجواب.

## النشر على VPS (Hostinger)

اختر قالب **Ubuntu 22.04 أو 24.04 نظيفاً** من لوحة Hostinger. لا تختر قالباً فيه لوحة تحكم (CyberPanel / Plesk) — ستحتل المنفذين 80 و443 وتتعارك مع nginx.

### ثلاث خطوات

```bash
ssh root@YOUR_VPS_IP

cd /opt && git clone <your-repo> ai-legal && cd ai-legal

bash deploy/setup-vps.sh            # Docker + swap + جدار ناري + توليد الأسرار
nano .env                           # الشيء الوحيد المطلوب يدوياً: OPENAI_API_KEY
bash deploy/deploy.sh               # بناء + ترحيل + تشغيل
bash deploy/setup-nginx.sh your-domain.com   # reverse proxy + HTTPS
```

`setup-vps.sh` يطبع **كلمة مرور الإدارة المولّدة مرة واحدة** — احفظها فوراً. كلمة مرور قاعدة البيانات والـ salt يُولَّدان عشوائياً ولا تحتاج رؤيتهما.

قبل `setup-nginx.sh`: وجّه سجل **A** للنطاق إلى IP الخادم وانتظر انتشار DNS. certbot يُثبت الملكية بجلب ملف عبر HTTP، وهذا مستحيل قبل أن يُترجم النطاق.

### ما تفعله السكربتات ولماذا

| السكربت | المهم فيه |
|---|---|
| `setup-vps.sh` | **2GB swap** — على خطة 4GB يبلغ `next build` ذروة ~1.5GB بينما Postgres يحتجز ~700MB. بلا swap يُقتل البناء ويظهر `exit code 137` الغامض بدل رسالة نفاد ذاكرة. |
| `deploy.sh` | ينتظر `pg_isready` لا مجرد إقلاع الحاوية — قاعدة قائمة لكنها ما زالت تعيد تشغيل WAL ترفض أول استعلام. |
| `setup-nginx.sh` | `proxy_buffering off` (بدونه يُحتجز البث كاملاً)، `client_max_body_size 25M` (بدونه يفشل رفع PDF بـ 413)، و`X-Forwarded-For` (بدونه كل الزوار من `127.0.0.1`). |
| `backup.sh` | يحفظ القاعدة **والملفات معاً**. الاستعادة من dump وحده تعطيك صفوفاً تشير إلى PDF غير موجودة، وكل إعادة فهرسة ستفشل. |

### الأمان

المنفذان `3000` و`5432` مربوطان بـ `127.0.0.1` في `docker-compose.yml`. **هذا الربط هو ما يحميهما فعلياً، لا الجدار الناري** — قواعد iptables التي يكتبها Docker تتجاوز ufw وتفتح المنافذ للإنترنت لو رُبطت بـ `0.0.0.0`. لا تغيّر هذا الربط.

### مصيدة معروفة

`POSTGRES_PASSWORD` يُطبَّق **عند تهيئة القاعدة أول مرة فقط**. إن شغّلت `docker compose up -d db` قبل `setup-vps.sh`، فالقاعدة أُنشئت بكلمة `legal` الافتراضية ولن يغيّرها تعديل `.env`. الحل على قاعدة فارغة:

```bash
docker compose down -v    # يمحو الـ volume — كل البيانات تضيع
bash deploy/setup-vps.sh
```

### الذاكرة

| الخطة | الحكم |
|---|---|
| 4GB | يعمل. Postgres 512MB shared_buffers، Node ~700MB، وOCR يقفز إلى ~1GB. الـ swap إلزامي وقد يتوقف التطبيق لحظياً أثناء فهرسة ملف ممسوح كبير. حاوية التطبيق مقيّدة بـ 1800MB لتُقتل وحدها بدل أن تُسقط Postgres معها. |
| 8GB | **موصى به** إن كنت ستفهرس قوانين ضخمة ممسوحة ضوئياً. الفرق في الوقت لا في القدرة. |

### النسخ الاحتياطي

```bash
crontab -e
0 3 * * * cd /opt/ai-legal && bash deploy/backup.sh >> /var/log/legal-backup.log 2>&1
```

Hostinger توفّر snapshots، لكنها لقطة للخادم كله لا للبيانات — لا تُغني عن dump تستطيع استعادة جدول منه.

## حدود هذا الإصدار (MVP)

هذه قرارات واعية لا نواقص مخفية:

- **الحدّ في الذاكرة** — يتضاعف صامتاً مع كل نسخة إضافية خلف load balancer. Redis قبل التوسّع أفقياً.
- **الفهرسة متزامنة** — رفع قانون ضخم يحجز الطلب لدقائق. طابور مهام هو الحل الصحيح عند الحجم، لكنه يعني Redis + worker على صندوق سعته 4GB.
- **مصادقة إدارية بكلمة واحدة** — لا سجل تدقيق لكل مسؤول، وتدوير الكلمة يُخرج الجميع. جدول `users` جاهز للانتقال إلى حسابات حقيقية.
- **OCR محدود بـ 40 صفحة** — بلا سقف، مسح من 400 صفحة يشلّ المعالج 20 دقيقة.
- **PDF المحذوف يبقى على القرص** — الصف يُحذف، والملف يبقى للاسترجاع. نظّفه بمهمة منفصلة.
- **استخراج البيانات الوصفية بالتعابير النمطية** — يُعيد `null` عند الشك بدل التخمين، لأن رقم قرار مُختلق أسوأ من حقل فارغ.
