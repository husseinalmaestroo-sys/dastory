# لماذا ليست روابط جاهزة مثل moj-laws-ar.txt:
# تحقّقنا بتاريخ 2026-07-18 من صفحات "القوانين" الثلاث على moj.gov.jo — لا يوجد
# فيها أيٌّ من هذه القوانين العشرة. موقع وزارة العدل ينشر 24 قانوناً فقط (كلها
# مفهرسة أصلاً: المدني، العقوبات، أصول المحاكمات، التنفيذ، ... إلخ). المصدر
# الرسمي الأشمل هو ديوان التشريع (lob.gov.jo)، لكنه — كما هو موثّق في ذاكرة
# المشروع — خلف جدار حماية (WAF) وواجهته مشفّرة (CryptoJS-AES)، فلا يمكن أتمتة
# تنزيله. تُنزَّل ملفاته يدوياً من المتصفح ثم يُشغَّل الأمر أدناه لكل قانون.
#
# طريقة الإدخال (بعد تنزيل PDF القانون في مجلد خاص به):
#   قانون أساسي (أصلي):
#     npm run ingest -- ./downloads/<slug> --type=law \
#         --category=<التصنيف> --effective-date=<YYYY-MM-DD>
#     (رقم القانون وسنته يُقرآن من عنوان الملف تلقائياً؛ إن لم يكونا في الاسم
#      مرّرهما: --law-number=<N> --year=<YYYY>)
#
#   قانون معدّل (يجب ربطه بالأصلي):
#     أدخِل الأصلي أولاً، خذ رقم مصدره (source id) من /admin أو من:
#       SELECT id, title FROM legal_sources WHERE title ILIKE '%<اسم القانون>%';
#     ثم:
#     npm run ingest -- ./downloads/<slug>-<year> --type=law \
#         --amends=<baseSourceId> --effective-date=<YYYY-MM-DD>
#
# ملاحظة عن الترميز: بعض ملفات الجريدة الرسمية / lob.gov.jo تُستخرَج كنص مشوّه
# (mojibake) بسبب خرائط خطوط معطوبة. خط الإدخال يكتشف ذلك تلقائياً (quality.ts)
# ويحجب أرقام المواد غير الموثوقة. إن ظهر تحذير mojibake، جرّب نسخة رقمية سليمة
# أو نسخة HTML من مصدر ثانوي موثوق قبل الاعتماد على أرقام موادها.
